# Техническое задание: Приложение «Курсы криптовалют»

## 1. Назначение приложения

Приложение отображает текущие курсы популярных криптовалют к доллару США (USD).
Источник данных — открытый API CoinGecko (https://www.coingecko.com/en/api).

## 2. Функциональные требования

| № | Требование | Описание |
|---|-----------|----------|
| 1 | Отображение курсов | Вывод списка из 5 криптовалют (BTC, ETH, BNB, SOL, XRP) с ценами в USD |
| 2 | Обновление данных | Кнопка «Обновить» — повторный запрос к API и обновление цен |
| 3 | Автообновление | При запуске приложение автоматически загружает актуальные курсы |
| 4 | Статус-бар | Отображение времени последнего обновления и источника данных |
| 5 | Обработка ошибок | При недоступности API — понятное сообщение пользователю |

## 3. Используемые технологии

- **Язык:** Python 3.10+
- **GUI:** Tkinter (встроенная библиотека)
- **HTTP-запросы:** urllib.request (встроенная библиотека)
- **Работа с JSON:** json (встроенная библиотека)
- **Система контроля версий:** Git (минимум 3 коммита)

## 4. Описание API

Используется бесплатный endpoint CoinGecko:

```
GET https://api.coingecko.com/api/v3/simple/price
    ?ids=bitcoin,ethereum,binancecoin,solana,ripple
    &vs_currencies=usd
```

Пример ответа:
```json
{
  "bitcoin": {"usd": 65000.0},
  "ethereum": {"usd": 3200.0},
  "binancecoin": {"usd": 580.0},
  "solana": {"usd": 150.0},
  "ripple": {"usd": 0.55}
}
```

## 6. Эскиз интерфейса

Интерфейс состоит из следующих элементов:

```
┌──────────────────────────────────────┐
│        Курсы криптовалют             │  ← Заголовок
│  Текущие курсы к USD (CoinGecko API) │  ← Подзаголовок
├──────────────┬───────────────────────┤
│ Криптовалюта │ Цена (USD)            │  ← Заголовок таблицы
├──────────────┼───────────────────────┤
│ Bitcoin(BTC) │ $65000.00             │
│ Ethereum(ETH)│ $3200.00              │  ← Данные (5 строк)
│ BNB (BNB)    │ $580.00               │
│ Solana(SOL)  │ $150.00               │
│ XRP (XRP)    │ $0.55                 │
├──────────────┴───────────────────────┤
│       [  Обновить  ]                  │  ← Кнопка обновления
├──────────────────────────────────────┤
│ Последнее обновление: 12:30:00       │  ← Статус-бар
│ Источник: CoinGecko                  │
└──────────────────────────────────────┘
```
